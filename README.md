# A ReelUp — 手機特效剪片網頁

純前端、不用伺服器：影片只在使用者手機上處理，不會上傳。

## 功能
- 上傳直式影片 → 時間軸加特效 → 匯出 MP4（可直接分享到相簿 / Reels）
- AI 人像去背（MediaPipe，在瀏覽器執行）
- 一鍵爆款範本、拖曳調整時間、自動儲存專案

## 特效清單（39 種）
| 分類 | 特效 |
|---|---|
| 爆款版型（6） | 環繞卡片牆、等級排名、頻道景深、對比拼貼、數字對比面板、開箱價格 |
| 剪輯風格（20） | 手撕紙條、霓虹發光、雜誌封面風、筆記卡片、剪輯時間軸、復古膠片、極簡白字、卡拉OK字幕、漫畫分格、VHS 錄影帶、剪報拼貼、大字報、電影寬銀幕、Y2K 亮片、手寫筆記、黑白高反差、彩色描邊／換背景、Podcast 訪談、分屏對比、便利貼 |
| AI 去背 | 人後大標、破框而出 |
| 文字 | 雙語字幕、金句字幕、玻璃字 |
| 鏡頭 | 數位推近 |
| 版面 | 筆記本拼貼、手機畫面 |
| 貼紙 | 個人檔案卡、打勾清單、收據列印、手繪塗鴉、長條成長 |

新增特效：在 `effects.js` 的 `EFFECTS` 加一個物件（params + draw），介面會自動產生。

## 本機執行
```bash
npx serve .
```
（必須用 http(s) 開，不能直接雙擊 index.html）

## 上線
把整個資料夾丟到 Netlify Drop / Vercel / GitHub Pages / Cloudflare Pages 即可。需要 HTTPS。

## 已知限制
- 匯出是「即時錄製」，10 秒影片要 10 秒
- 建議 3 分鐘以內的影片
- iOS 需 Safari 15+，Android 需 Chrome

## AI 模型檔
`vendor/` 內是 @mediapipe/tasks-vision 0.10.14（Apache-2.0）與 selfie_segmenter 模型（以 base64 JS 模組存放），全部自己託管，不依賴外部 CDN。

## 檔案
- `effects.js`：基本特效、共用工具
- `effects-pro.js`：6 個爆款版型
- `effects-styles.js`：20 種剪輯風格
- `grader.js`：電影感調色（WebGL）
- `segmenter.js`：AI 去背（快速 / 高品質兩種模型）

## 語音剪輯（✂️ 剪輯）
- **語音辨識**：Whisper（transformers.js），在手機上執行，音訊不上傳。模型第一次從 Hugging Face 下載（標準約 80MB／高準確約 250MB），之後瀏覽器會快取。需要放在正式網址才能下載模型。
- **只剪氣口**：不用辨識，直接分析聲音音量，任何環境都能用。
- **自動剪**：氣口、語氣詞（清單可自訂）、重複（我我我、我覺得我覺得）。
- **細節修改**：每個字詞、每個氣口都能點一下切換剪掉／保留；可以改字幕文字、微調每句的開始和結束時間；規則（氣口長度、安靜門檻、前後保留、每句字數）都可以調。
- **產生字幕**：一鍵把逐字稿變成字幕（雙語字幕、極簡白字、卡拉OK、手寫筆記、黑白高反差），也可以匯出或匯入 SRT。
- 檔案：`speech.js`（分析邏輯）、`transcribe-worker.js`（辨識）、`vendor/opencc-cn2t.js`（簡轉繁，MIT）
